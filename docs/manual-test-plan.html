0. Подготовка

Стенд
Бэк на http://localhost:3000, фронт на http://localhost:5173 (запросы /api/* фронт проксирует на бэк). Swagger: http://localhost:3000/api/docs.
Окна
Сессия хранится в cookie, поэтому каждому аккаунту — свой профиль браузера: О — Chrome, профиль «Owner»; А — Chrome, профиль «Admin»; М — Firefox или Safari (мастер Маша); П — Chrome, профиль «Petr» (мастер Пётр); Б — Chrome Incognito (второй владелец). Окно инкогнито живёт до закрытия всех инкогнито-окон.
Аккаунты
Таблица «Аккаунты: логины и пароли» вверху страницы (кнопка «Аккаунты» в углу ведёт к ней). Окна не выходить: Пётр заводится в отдельном окне П, чтобы Маша в окне М осталась в системе.
Данные для календаря
Сценарии 37–46 опираются на данные сценариев 9–16: у Маши рабочие часы на всю неделю с шагом записи 30 минут (сценарий 11), у Петра режим Groups с группами «Футбол дети» (12 мест) и «Йога» (1 место) на каждый день (сценарии 14–16). Нужные по времени занятия («началось 30 минут назад», «через 2 часа») подстройте под текущий час через Change у группы.
Лимиты
Бэк пускает 10 регистраций в час с одного IP и 5 неудачных входов на аккаунт за 15 минут. Лимиты в памяти: перезапуск бэка их сбрасывает.

    http://localhost:3000/health отвечает OK. Если на :3000 уже работает старый бэк — остановите его или запустите новый на другом порту (PORT=3001) и в шаге 2 задайте API_PROXY_TARGET=http://localhost:3001.
  2. В BookedUp-front: git switch main && git pull, npm ci, npm run dev.
    В терминале http://localhost:5173/.
  3. В окне О откройте http://localhost:5173.
    Адрес меняется на /sign-in, заголовок «Sign in».
  4. Проверьте язык браузера: во всех окнах английский первым (Chrome → Settings → Languages), кроме сценария 18.
